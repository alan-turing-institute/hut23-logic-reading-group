\section{Preliminaries}

In the following, ``the book'' means \emph{forall x: Calgary}.

\subsection{Arguments in English}
\label{sec:english}
A \defn{sentence} is a statement that could in principle be true or
false.  It is not, for example, a question or an interjection.  (The
book says that ``a \textsc{sentence} [is] a sentence that can be true or
false'' which seems circular.  On the other hand, I have not defined a
``statement.'')

An \defn{argument} is a finite sequence of sentences.  The final sentence is called the \defn[conclusion, premises]{conclusion}; the other sentences are called the \defn*{premises}. 

A \defn{counterexample} to an argument is a situation in which all the
premises are true but the conclusion is false.  An argument is
\defn[valid / invalid]{valid} if it has no counterexamples.  Thus, an
argument is valid if, whenever the premises are all true, then
necessarily the conclusion is true.  An argument that is not valid is
\defn*{invalid}.

The conclusion of a valid argument may be false if its premises are false.  A valid argument whose premises are true is \defn{sound}. If an argument is sound then, indeed, its conclusion may be judged to be true. 

If it is not possible for a sentence to be false, it is \defn[necessary
truth / falsehood]{necessarily true}.  For example: ``The number 7 is
either odd or even.''  If it is not possible for a sentence to be true,
it is \defn*{necessarily false}.  A sentence that is neither necessarily
true nor necessarily false is called \defn{contingent}.

Two sentences are \defn{jointly equivalent} if in all cases either they
are both true or they are both false.  A set of sentences are
\defn[jointly possible / impossible]{jointly possible} if there is a
case in which they are all true; sentences that are not jointly possible
are \defn*{jointly impossible}.

\sidenote*{The book refers to the logic developed in parts II to~IV\ as
  \emph{truth-functional logic}, or TFL\@.  Truth-functional logic is
  also known as \emph{propositional logic} and sometimes
  \emph{sentential logic} (see Appendix~A.1 of the book).  The Stanford
  Encyclopedia of Philosophy calls it propositional logic, so that is
  what I shall do.}
\section{Propositional logic}

\subsection{Syntax}
We assume the existence of a countable set of \defn[sentence
letter]{sentence letters}: $A$, $B$, \ldots, $A_1$, $A_2$, \ldots,
$C_{42}$, \ldots.  The symbols $\wedge$, $\vee$, $\to$,
$\leftrightarrow$, and $\neg$ are known as \defn[connectives ($\wedge$,
$\vee$, $\to$, $\leftrightarrow$, and $\neg$)]{connectives}.  A \defn[sentence (or ``proposition'')]{sentence} (of
propositional logic) is defined by the grammar shown in
figure~\ref{fig:bnf-prop}.

\begin{figure}[ht]
  \sidecaption{\label{fig:bnf-prop}The meaning of ``sentence'' in
    propositional logic.  Here \wff{S}, \wff{A}, and \wff{B} are
    arbitrary sentences.  An alternative name for a sentence is a
    \emph{well-formed formula}. Sometimes the symbols $\top$ (``top,'' or
    ``truth'') and $\bot$ (``bottom,'' or ``false'') are also allowed as
    sentences.}
  \centering
  \begin{bnf}
    $\wff{S}$ : Sentence ::=
    | $A$ // $B$ // $C$ // $\dotsb$        : atomic sentence
    |  $\neg \wff{A}$                      : negation
    | ($\wff{A} \wedge \wff{B}$)           : conjuction 
    | ($\wff{A} \vee \wff{B}$)             : disjunction
    | ($\wff{A} \to \wff{B}$)              : conditional
    | ($\wff{A} \leftrightarrow \wff{B}$)  : biconditional
  \end{bnf}
\end{figure}

It is traditional, when writing a sentence, to omit the outer set of
parentheses and to allow the use of other kinds of brackets, such as `['
and `]', wherever parentheses may be used. It is also traditional (but
this is not a tradition followed by the book) to omit many other
parentheses when the result can be disambiguated according to the
following rules: \sidenote*{I tend to think of the \emph{real} thing as
  a kind of data type, or perhaps a tree.  The sentence is just how we
  serialise it.  That is, I understand, say, ``a conjunction'' to simply
  be a kind of sentence, the constituent data for which is a pair of
  sentences (namely, the left conjunct and the right conjunct).  It
  doesn't matter how it is \emph{written}, what it \emph{is} is a
  conjunction.  The only reason we care about how we write it is to
  ensure that we can recover the real thing given the written form. I don't know whether this view is right.}
\begin{enumerate}
\item $\neg$ binds more tightly than $\wedge$ and $\vee$, which bind more tightly
  than $\to$ and $\leftrightarrow$;
\item $\wedge$ and $\vee$ are associative so it doesn't matter how you replace the parentheses in, for example, $P\wedge Q\wedge R$; and
\item $\to$ is taken to be right associative.
\end{enumerate}
Thus $P\wedge Q\to R$ means $(P\wedge Q)\to R$; $P\to Q\to R$ means $P \to (Q \to R)$; and $P\wedge Q \wedge R$ may be read as either $(P\wedge Q)\wedge R$ or $P\wedge (Q\wedge R)$, as you like.

\subsection{Object language and metalanguage}

The grammar of figure~\ref{fig:bnf-prop} defines the set of possible
sentences in propositional logic. However, the terms `\wff{S}',
`\wff{A}', and `\wff{B}', (written in a script typeface) are not
themselves either sentences or parts of sentences.  They cannot be, for
they are neither atomic propositions nor sentences made from atomic
propositions and connectives.  Instead they \emph{stand for} arbitrary sentences.  Whereas `$P$', `$Q$', and so on are propositional variables, which are truth-valued, the script variables, `\wff{A}', `\wff{B}', and so on are \defn{metavariables} and are ``sentence valued.'' 

Propositional variables, and sentences generally, make up the
\defn{object language} of propositional logic.  Metavariables and other
terms used to described the object language are said to be part of the
\defn{metalanguage}.

\section{Semantics}

\subsection{Valuations}

A \defn[truth values ($\tr$ and $\fa$)]{truth value} is one of `$\tr$'
(true) or `$\fa$' (false).  (The lighter shade for $\fa$ is just to make
it clearer which is which.)  Sentences are the kind of thing that may
have truth values.  A \defn{valuation} is an assignment of a truth value
to each of a set of sentence letters.  A \defn{truth table} for a
sentence is a set of rows, each giving a possible valuation of the
sentence letters in the sentence together with the value of the whole
sentence.  (The truth value of a compound sentence is determined
entirely by the truth values of its constituent parts and the particular
connectives.)  See figure~\ref{fig:truthtables} for complete truth
tables of the standard connectives.

\subsection{Arguments (reprise)}

We now recapitulate the ideas of section~\ref{sec:english} as they apply to propositional logic rather than in general.

A sentence, \wff{S}, is a \defn[tautology, contradiction]{tautology} if
it is true on every valuation.  Likewise, \wff{S} is a
\defn*{contradiction} if it is false on every valuation.  ``Tautology''
and ``contradiction'' are the the propositional logic versions of
``necessary truth'' and ``necessary falsehood'' respectively.

Two sentences, \wff{A} and \wff{B}, are \defn{equivalent} if their truth values agree on every valuation.

Sentences $\wff{A}_1, \wff{A}_2, \dotsc, \wff{A}_n$ are \defn[jointly
satisfiable / unsatisfiable]{jointly satisfiable} if there is some
valuation that makes them all true.  Likewise these sentences are
\defn*{jointly unsatisfiable} if there is no valuation that makes them
all true.  These concepts are the propositional logic versions of
``jointly possible'' and ``jointly impossible'' respectively.

Sentences $\wff{A}_1, \wff{A}_2, \dotsc, \wff{A}_n$ \defn[entailment, $\vDash$]{entail} sentence $\wff{C}$ if there is no valuation that makes all the $\wff{A}_i$ true and $\wff{C}$ false.  If indeed the $\wff{A}_i$ entail $\wff{C}$ we write
\begin{equation*}
  \wff{A}_1, \wff{A}_2, \dotsc, \wff{A}_n \vDash \wff{C}.
\end{equation*}

Entailment is the propositional logic version of validity. If
$\wff{A}_1, \dotsc, \wff{A}_n \vDash \wff{C}$, then the argument
$\wff{A}_1, \dotsc, \wff{A}_n\, \therefore \wff{C}$ is valid.  The converse is
not necessarily true since in English, but not in propositional logic,
one may appeal to the meaning of the sentence letters to establish
validity.

If $\wff{C}$ is a tautology we may write $\vDash \wff{C}$. Likewise, if $\wff{C}$ is a contradiction we may write $\wff{C} \vDash$. If the sentences $\wff{A}_1,\dotsc, \wff{A}_n$ are jointly unsatisfiable, we may write $\wff{A}_1,\dotsc, \wff{A}_n \vDash$.

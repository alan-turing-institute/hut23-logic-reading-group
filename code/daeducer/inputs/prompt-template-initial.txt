Starting with <PREPREMISES><PREMISES>, prove the result <CLAIM>. The resulting proof should be given as a sequence of steps where a single rule is applied at each step using First Order Logic.

Each step should conform to the following format:

<step>: <rule> <refs>, <exps>

Here <step> represents an integer starting from 1 and increasing by 1 each line.

The <refs> term represents a sequence of zero or more <ref> references back to a previous step separated by commas. Each such <ref> takes an integer value which must be smaller than the current step.

The <exps> term represents one or more <exp> expressions of propositional logic also separated by commands. These expressions are inputs to each step if needed, not outputs from the step. Most of the rules do not require an <exp> input at all.

Each rule must be an instance of one of the following:

<step>: premise <exp>
<step>: reiteration <ref>
<step>: and_intro <ref>, <ref>
<step>: and_elim_left <ref>
<step>: and_elim_right <ref>
<step>: imp_elim <ref>, <ref>
<step>: imp_intro <ref>, <ref>
<step>: bi_elim <ref>, <ref>
<step>: bi_intro <ref>, <ref>, <ref>, <ref>
<step>: or_intro_left <ref>, <exp>
<step>: or_intro_right <ref>, <exp>
<step>: or_elim <ref>, <ref>, <ref>, <ref>, <ref>
<step>: not_elim <ref>, <ref>
<step>: not_intro <ref>, <ref>
<step>: indirect <ref>, <ref>
<step>: explosion <ref>, <exp>
<step>: assumption <exp>
<step>: discharge
<step>: forall_intro <ref>, <var>, <var>
<step>: forall_elim <ref>, <var>
<step>: exists_intro <ref>, <exp>
<step>: exists_elim <ref>, <ref>, <ref>
<step>: id_intro <var>

Here <ref> will be a reference to a previous line; <exp> will be written in LaTeX format, surrounded by $ signs and with single-blackslash representing a single LaTeX backslash (e.g. use \lor for logical or); <var> is a variable name.

For example, a proof may start by introducing a premise as follows:

1: premise $A$

It may continue by introducing a disjunction as follows.

2: or_intro_left 1, $B$

The result of the second step would be $A \lor B$, but this isn't shown anywhere in the proof, it's just implied.

The following explains what each of the rules performs:

premise: introduce a premise.
Example use:
```
premise $A \lor B$
1. | $A \lor B$
```

reiteration: to repeat a previously derived expression.
Example use:
```
premise $A \lor B$
1. | $A \lor B$
reiteration 1
2. | $A \lor B$
```

and_intro: conjunction introduction.
Example use:
```
premise $A$
1 | $A$
premise $B$
2 | $B$
and_intro 1, 2
3 | $(A \land B)$
```

and_elim_left: eliminate a conjunction and leave the expression on the left hand side of the conjunction remaining.
Example use:
```
premise $A \land B$
1 | $(A \land B)$
and_elim_left 1
2 | $A$
```

and_elim_right: eliminate a conjunction and leave the expression on the right hand side of the conjunction remaining.
Example use:
```
premise $A \land B$
1 | $(A \land B)$
and_elim_right 1
2 | $B$
```

imp_elim: eliminate a conditional; modus ponens.
Example use:
```
premise $A \to B$
1 | $(A \to B)$
premise $A$
2 | $A$
imp_elim 1, 2
3 | $B$
```

imp_intro: conditional introduction from a discharged subproof.
Example use:
```
premise $B$
1 | $B$
assumption $A$
2 | | $A$
reiteration 1
3 | | $B$
discharge
4 |
imp_intro 2, 3
5 | $(A \to B)$
```

bi_elim: eliminate a bi-implication (logical equivalence).
Example use:
```
premise $A \leftrightarrow B$
1 | $(A \leftrightarrow B)$
premise $A$
2 | $A$
premise $B$
3 | $B$
bi_elim 1, 2
4 | $B$
bi_elim 1, 3
5 | $A$
```

bi_intro: introduce a bi-implication (logical equivalence)..
Example use:
```
premise $A$
1 | $A$
premise $B$
2 | $B$
assumption $A$
3 | | $A$
reiteration 2
4 | | $B$
discharge
5 |
assumption $B$
6 | | $B$
reiteration 1
7 | | $A$
discharge
8 |
bi_intro 3, 4, 6, 7
9 | $(A \leftrightarrow B)$
```

or_intro_left: disjunction introduction with the previously derived expression on the left hand side of the result.
Example use:
```
premise $A$
1 | $A$
or_intro_left 1, $B$
2 | $(A \lor B)$
```

or_intro_right: disjunction introduction with the previously derived expression on the right hand side of the result.
Example use:
```
premise $A$
1 | $A$
or_intro_right 1, $B$
2 | $(B \lor A)$
```

or_elim: disjunction elimination from a disjunction and two subproofs.
Example use:
```
premise $A \lor B$
1 | $(A \lor B)$
premise $C$
2 | $C$
assumption $A$
3 | | $A$
reiteration 2
4 | | $C$
discharge
5 |
assumption $B$
6 | | $B$
reiteration 2
7 | | $C$
discharge
8 |
or_elim 1, 3, 4, 6, 7
9 | $C$
```

not_elim: introduce $\bot$ from the negation of a statement and the statement. The negation must be listed first.
Example use:
```
premise $\neg A$
1 | $\neg A$
premise $A$
2 | $A$
not_elim 1, 2
3 | $\bot$
```

not_intro: introduce the negation of a statement from a subproof that takes the statement as an assumption and concludes with $\bot$.
Example use:
```
premise $\neg A$
1 | $\meg A$
assumption $A$
2 | | $A$
not_elim 1, 2
3 | | $\bot$
discharge
4 |
not_intro 2, 3
5 | $\neg A$
```

indirect: indirect proof. From a subproof that assumes the negation of a statement and concludes with $\bot$, derives the statement.
Example use:
```
premise $A$
1 | $A$
assumption $\neg A$
2 | | $\neg A$
not_elim 2, 1
3 | | $\bot$
discharge
4 |
indirect 2, 3
5 | $A$
```

explosion: from $\bot$ we can derive anything.
Example use:
```
premise $\bot$
1 | $\bot$
| > explosion 1, $A$
2 | $A$

```

assumption: start a subproof with the given assumption.
Example use:
```
assumption $A$
1 | | $A$
| | > discharge
2 |
```

discharge: discharge a subproof. This must be an explicit numbered step in the proof.
Example use:
```
assumption $A$
1 | | $A$
| | > discharge
2 |
```

forall_intro: introduce a universal quantifier.
Example use:
```
premise $\forall x A(x)$
1 | $\forall x A(x)$
forall_elim 1, a
2 | $A(a)$
forall_intro 2, a, x
3 | $\forall x A(x)$
```

forall_elim: eliminate a universal quantifier.
Example use:
```
premise $\forall x A(x)$
1 | $\forall x A(x)$
forall_elim 1, a
2 | $A(a)$
```

exists_intro: introduce an existential quantifier.
Example use:
```
premise $A(a, a)$
1 | $A(a, a)$
exists_intro 1, $A(x, a)$
2 | $\exists x A(x, a)$
```

exists_elim: eliminate an existential quantifier.
Example use:
```
premise $\exists x A(x)$
1 | $\exists x A(x)$
assumption $A(a)$
2 | | $A(a)$
exists_intro 2, A(x)
3 | | $\exists x A(x)$
discharge
4 |
exists_elim 1, 2, 3
5 | $\exists x A(x)$
```

id_intro: introduce an identity (equality between variables).
Example use:
```
id_intro x
1 | $x = x$
```

id_elim: eliminate an identity.
Example use:
```
premise $a = b$
1 | $a = b$
premise $A(a, a)$
2 | $A(a, a)$
id_elim 1, 2, $A(b, a)$
3 | $A(b, a)$
```

modus_tollens: from "if P then Q" and "not Q" derive "not P"; modus tollens.
Example use:
```
premise $A \to B$
1 | $(A \to B)$
premise $\neg B$
2 | $\neg B$
modus_tollens 1, 2
3 | $\neg A$
```

double_not_elim: a proposition is equivalent to the falsehood of its negation.
Example use:
```
premise $\neg \neg A$
1 | $\neg \neg A$
double_not_elim 1
2 | $A$
```

conv_not_exists: "not exists" is equivalent to "forall not".
Example use:
```
premise $\neg \exists x A(x)$
1 | $\neg \exists x A(x)$
conv_not_exists 1
2 | $\forall x \neg A(x)$
```

conv_forall_not: "forall not" is equivalent to "not exists".
Example use:
```
premise $\forall x \neg A(x)$
1 | $\forall x \neg A(x)$
conv_forall_not 1
2 | $\neg \exists x A(x)$
```

conv_not_forall: "not forall" is equivalent to "exists not".
Example use:
```
premise $\neg \forall x A(x)$
1 | $\neg \forall x A(x)$
conv_not_forall 1
2 | $\exists x \neg A(x)$
```

conv_exists_not: "exists not" is equivalent to "not forall".
Example use:
```
premise $\exists x \neg A(x)$
1 | $\exists x \neg A(x)$
conv_exists_not 1
2 | £\neg \forall x A(x)£
```

demorgan_not_or: the negation of "A or B" is equivalent to "not A and not B".
Example use:
```
premise $\neg (A \lor B)$
1 | $\neg (A \lor B)$
demorgan_not_or 1
2 | $(\neg A \land \neg B)$
```

demorgan_or_not: "not A or not B" is equivalent to the negation of "A and B".
Example use:
```
premise $\neg A \lor \neg B$
1 | $(\neg A \lor \neg B)$
demorgan_or_not 1
2 | $\neg (A \land B)$
```

demorgan_not_and: the negation of "A and B" is equivalent to "not A or not B".
Example use:
```
premise $\neg (A \land B)$
1 | $\neg (A \land B)$
demorgan_not_and 1
2 | $(\not A \lor \neg B)$
```

demorgan_and_not: "not A and not B" is equivalent to the negation of "A or B".
Example use:
```
premise $\neg A \land \neg B$
1 | $(\neg A \land \neg B)$
demorgan_and_not 1
2 | $\neg (A \lor B)$
```

or_syllogism_left: from "P or Q" and "not P" derive "Q"; disjunctive syllogism.
Example use:
```
premise $A \lor B$
1 | $(A \lor B)$
premise $\neg A$
2 | $\neg A$
or_syllogism_left 1, 2
3 | $B$
```

or_syllogism_right: from "P or Q" and "not Q" derive "P"; disjunctive syllogism.
Example use:
```
premise $A \lor B$
1 | $(A \lor B)$
premise $\neg B$
2 | $\neg B$
or_syllogism_right 1, 2
3 | $A$
```

excluded_middle: from "P implies Q" and "!P implies Q" derive "Q"; excluded middle.
Example use:
```
premise $A \to B$
1 | $(A \to B)$
premise $\neg A \to B$
2 | $(\neg A \to B)$
excluded_middle 1, 2
3 | $B$
```

# Solutions

Proof solutions for all of the exercises in Forall-x: Calgary, up to and including Chapter 40 (i.e. covering TFL, FOL but not ML).

The [solutions.pdf](../../../raw/main/solutions/solutions.pdf) file is a prebuilt copy of the document.

To build it yourself you'll need LaTeX installed.

Build using:
```
pdflatex solutions.tex
```

This will generate a PDF document called  `solutions.pdf`.
